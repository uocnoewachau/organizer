# Парафіяльний органайзер Вахау · 1.57.0

## Публікація на GitHub Pages
Завантажте в корінь репозиторію всі елементи, зберігаючи структуру: `index.html`, `manifest.webmanifest`, `service-worker.js`, `icons/icon.svg`.

У GitHub відкрийте **Settings → Pages** і встановіть Source: **Deploy from a branch**, Branch: **main**, Folder: **/(root)**.

Очікувана адреса: https://uocnoewachau.github.io/wachau-parish-organize/

## Важливо про дані
Органайзер зберігає записи локально у браузері; GitHub Pages не синхронізує їх між пристроями. Не додавайте до публічного репозиторію резервні копії, реєстри, персональні або пастирські дані. Резервні копії зберігайте окремо та безпечно.
